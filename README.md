# 🎓 우리 반 자리 바꾸기 (Classroom Seat Manager)

> **학교 교실 자리 바꾸기를 쉽고, 공정하며, 아름답게!**  
> 서버 없이 브라우저에서 100% 동작하는 교사용 스마트 교실 자리 배치 웹 애플리케이션입니다.

---

## 🌟 주요 기능 소개

### 1. 📐 자유로운 교실 구조 커스텀 (Step 1)
- **행 × 열 크기 조절**: 교실 크기에 맞게 1×1 ~ 10×10까지 자유롭게 책상 배열 조절
- **책상 유형 토글**: 책상을 클릭하는 것만으로 `1인석 ↔ 2인석 ↔ 통로(빈 공간)` 즉시 전환
- **교탁/칠판 위치 전환**: 교실 앞쪽(학생 시선) 또는 교실 뒤쪽(교사 시선) 설정 가능
- **원클릭 프리셋**: 5×6 (30석), 6×5 (1인석 30석), 4×6 (24석), 5×5 (25석), 3분단 분단형 구조 등 원클릭 적용
- **실시간 정원 계산**: 총 책상 수, 1인석/2인석 수, 전체 수용 인원 및 학생 수 대비 좌석 여유/부족 자동 계산

### 2. 📥 스마트 학생 명단 관리 & 엑셀 지원 (Step 2)
- **엑셀 파일 드래그 앤 드롭**: `.xlsx`, `.xls`, `.csv` 파일을 드래그하여 명단 즉시 로드
- **표준 양식 다운로드**: `학생명단_업로드양식.xlsx` 파일을 바로 다운로드하여 작성 가능 (열: 번호, 이름, 성별)
- **25명 샘플 즉시 불러오기**: 테스트 및 시연을 위한 25명 모범 샘플 명단 원클릭 로드
- **학생 개별 관리**: 학생 번호, 이름, 성별(남/여) 추가, 실시간 수정, 삭제 및 실시간 검색 필터링

### 3. 🤝 강력한 자리 배치 조건 & 실시간 상충 감지 (Step 3)
- **🤝 같이 앉기 (짝궁 지정)**: 친하게 지내야 하거나 도우미 역할이 필요한 두 학생을 같은 2인석에 짝으로 자동 배치
- **🚫 같이 앉지 않기 (거리두기)**: 수업 집중이나 생활지도를 위해 같은 책상에 앉지 않아야 하는 학생 분리
- **실시간 충돌 감지 (Conflict Detector)**:
  - 중복 짝궁 지정 오류
  - 모순된 조건 (동일 학생을 동시에 같이 앉기 + 떨어져 앉기 지정)
  - 좌석 부족 경고 (학생 수 > 총 좌석 수)
  - 짝궁 조건 수가 교실 내 2인석 책상 수를 초과하는 경우 사전 경고

### 4. 🎲 공정 추첨 알고리즘 & 인터랙티브 시각화 (Step 4)
- **제약 만족 무작위 셔플링**: 최대 1,000회 시도를 통해 모든 조건을 만족하는 완벽한 무작위 배치 산출
- **축하 폭죽 연출**: 자리 배치가 성공적으로 완료되면 브라우저 화면에 Confetti 폭죽 애니메이션 발사
- **🖱️ 클릭 자리 맞바꾸기 (Click-to-Swap)**: 배치 완료 후 미세 조정이 필요할 때 좌석 2개를 클릭하여 학생 위치 즉시 교환
- **날짜 기록**: 자리 바꾸기를 실행한 날짜(연/월/일) 자동 기록

### 5. 📚 자리 배치 기록 보관함 & A4 인쇄 출력 (Step 5)
- **로컬 스토리지 자동 저장**: 브라우저를 닫거나 새로고침해도 설정과 명단이 안전하게 유지
- **히스토리 보관함**: "2학기 1차 자리배치", "중간고사 후 자리" 등 날짜와 이름을 붙여 스냅샷 저장 및 원클릭 복원
- **🖨️ A4 가로 최적화 인쇄 서식 (`@media print`)**:
  - 학급명, 자리 바꾸기 날짜, 학생 수 표시
  - 교실 배치도 (칠판, 교탁, 1인석/2인석/통로, 학생 번호, 이름, 성별) 깔끔 출력
  - 교실 게시 및 결재용 **담임교사 서명란** 포함
- **📤 데이터 백업 & 📥 복원**: 다른 PC나 교실 컴퓨터로 이동할 때 전체 데이터를 `.json` 파일로 내보내기/가져오기 가능

## 🚀 시작 및 실행 방법

### 방법 1. 브라우저에서 바로 열기 (가장 간단)
1. 다운로드받은 폴더에서 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 웨일 등 브라우저로 엽니다.
2. 인터넷 연결 없이도 모든 기능이 100% 오프라인에서 동작합니다.

### 방법 2. 로컬 웹서버로 실행하기 (선택 사항)
```bash
cd classroom-seat-manager
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속

## 🌐 GitHub Pages 무료 배포 방법

이 프로젝트는 백엔드 서버나 빌드 과정이 필요 없는 순수 바닐라 웹앱이므로 GitHub Pages에 1분 만에 배포할 수 있습니다.

1. GitHub에서 새로운 저장소(Repository)를 생성합니다 (예: `classroom-seat-manager`).
2. 프로젝트의 모든 파일을 저장소의 `main` 브랜치에 푸시(Push)합니다.
3. 저장소의 **Settings** > **Pages** 메뉴로 이동합니다.
4. **Branch**를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 클릭합니다.
5. 잠시 후 제공되는 웹 링크(`https://<사용자이름>.github.io/classroom-seat-manager/`)로 어디서나 접속할 수 있습니다!
